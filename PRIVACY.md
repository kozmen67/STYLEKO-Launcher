# Privacy policy

STYLEKO Launcher does not include analytics, advertising SDKs, or telemetry intended to collect personal user data.

The launcher performs network communication required for its normal operation:

- It connects to the launcher server configured in `Server.ini` on TCP port 15100 to retrieve version, notice, and patch metadata.
- When an update is required, it connects to the patch server returned by the launcher service to download patch archives.
- The STYLEKO website is opened in the user's default browser only when the user selects the Home action.

The launcher may receive server-provided update information and download files required to update the local game installation. It does not intentionally transmit account credentials, character data, chat messages, or other game-session content.

Microsoft Edge WebView2 is used to display local launcher and guard HTML files. Any privacy behavior of third-party services intentionally opened by the user is governed by those services' own policies.

For questions about this policy, use the project's GitHub issue tracker.

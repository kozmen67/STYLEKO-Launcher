# Contributing

STYLEKO Launcher uses a review-first contribution model for contributors who are not repository committers.

1. Open an issue or pull request describing the change.
2. Keep launcher behavior, build scripts, and release changes auditable.
3. A project reviewer must review changes from non-committers before merge.
4. Changes to GitHub Actions, release packaging, signing configuration, or artifact metadata receive the same review requirement.
5. Production signing requests require a separate manual approval.

Security-sensitive reports should avoid publishing exploit details in a public issue.
